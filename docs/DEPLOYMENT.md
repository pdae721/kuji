# AWS 배포 기록

- 대상: AWS 서울 리전 `ap-northeast-2`, 무료 플랜 계정.
- 방식: `deploy/ec2.yaml` CloudFormation, `deploy/bootstrap.sh` 초기화.
- 상태: 배포 준비 및 검증 중. 실제 생성·검증 후 갱신합니다.
- 배포 주소: 아직 미확정.
- 배포 커밋: 아직 미확정.
- 스택 상태: 아직 미확정.

무료 플랜은 크레딧으로 사용 비용을 충당하며, 플랜 종료 또는 크레딧 소진 시 서비스가 종료될 수 있습니다. 유료 플랜으로 전환하지 않았습니다. 영구 무료라는 뜻은 아닙니다.

완료 증거는 배포 주소의 실제 HTTP 입력·응답 `evidence/deployment-http.json`과 배포 화면으로 남깁니다. AWS 로그인 정보·자격 증명·계정 식별 정보는 이 문서에 넣지 않습니다.
