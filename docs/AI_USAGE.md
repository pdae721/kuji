# AI 활용 기록

과제의 AI 허용 범위 원문은 제공되지 않았습니다. 실제 대화·도구 실행을 기록하며 규정 준수를 임의로 인증하지 않습니다.

| 구분 | 실제 수행 |
|---|---|
| 사용자가 제공한 것 | 상품 이미지18장, 상·캐릭터별 재고 조건, 기능2개 요청, AWS 배포 요청·평가 항목, 무료 사용 조건 |
| AI(Codex)가 구현을 지원한 것 | 이미지·API 연결, 재고 그룹화, 검색·필터, 확률 계산·표시, API 시험, 배포 템플릿·스크립트, README·검증 문서 |
| AI가 실행한 시험 | Node5건, API8건, 브라우저 정상 검색·빈 결과·초기화·375px 확인. AWS 실제 결과는 배포 기록에 별도 기재 |
| 사용자가 직접 수행한 것 | 요구사항·사진·재고 지정, AWS 계정 로그인, 무료 사용 조건 선택 |
| 아직 사람의 실행으로 확인하지 않은 것 | 배포 주소에서 학생이 직접 기능별 정상·실패 시험을 실행하고 설명하는 과정 |

기존 파일·변경 사항이 작업 전부터 있었습니다. 기존 코드 전체를 AI 또는 학생 한쪽이 독자 작성했다고 단정하지 않습니다. 실제 사람의 시험은 `VALIDATION.md`의 직접 실행 기록에 추가해야 합니다.
